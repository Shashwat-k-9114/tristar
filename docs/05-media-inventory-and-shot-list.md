**Rules in force**
- No AI-generated food imagery and no fabricated depictions of the premises. Stock may be used only for conceptual atmosphere (steam, smoke, texture) — never as a stand-in for a menu item.
- No hotlinked stock previews. Licensed files are downloaded, recorded in this table (source URL, licence text/ID, purchase receipt) and self-hosted.
- Every real photo/video row must be completed (source, rights holder, usage scope and term, attribution, file path, optimisation status) before merge.

## B. Delivery spec for client media (so it never breaks the performance budget)

| Item | Deliver | We publish as |
|---|---|---|
| Photos | Original RAW/JPEG ≥ 3000 px long edge, sRGB, minimal retouch | AVIF + WebP via `next/image`, hero ≤ 120 KB mobile, ≤ 200 KB desktop |
| Hero video (optional) | 1080p, 8–12 s seamless loop, no audio, H.264 + AV1/VP9 | ≤ 1.2 MB mobile (≤ 720p), ≤ 3 MB desktop, `preload="none"`, loaded after LCP, **static poster ≤ 80 KB** always present; never autoplays under reduced motion or Save-Data |
| Logo | Final vector (SVG/AI/PDF), transparent | `public/brand/` |
