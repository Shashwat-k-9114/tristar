DISH PHOTOS
Run  python download_dish_photos.py  (from the project root). It downloads free-licensed photos into this folder and writes CREDITS.txt.
Then run  npm run photos  to regenerate lib/dish-photos.json — the menu shows a photo for every dish listed there.
To use your own photo for a dish: save it here as <dish-name>.jpg (lowercase, hyphens: mutton-biryani.jpg) and run  npm run photos.
Dish photos are illustrative and come from Wikimedia Commons.
